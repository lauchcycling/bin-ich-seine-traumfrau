# bin-ich-seine-traumfrau

Ein minimalistisches, mobiloptimiertes Web-Projekt für Vercel.

## Bereitstellung auf Vercel

### Option 1: Vercel CLI
```bash
npx vercel
```

### Option 2: GitHub / Vercel Dashboard
Repository auf GitHub pushen und in [Vercel](https://vercel.com) importieren.

## Lokale Vorschau
Einfach die `index.html` im Browser öffnen oder mit einem beliebigen Webserver starten:
```bash
npx serve .
```
